# SpendWise Tracker 💸

**Master your money, privately and simply.**

SpendWise Tracker is a privacy-focused, client-side budget management dashboard. It allows you to track income and expenses, visualize your spending habits, and maintain control over your finances without sending data to the cloud.

## 🚀 Features

- **Instant Tracking**: Add income and expenses in seconds.
- **Data Privacy**: All data is stored in your browser's Local Storage. Nothing leaves your device.
- **Visual Insights**: Interactive charts to break down spending by category.
- **Financial Overview**: Real-time calculation of balance and cash flow.
- **Responsive**: Works perfectly on desktop and mobile.

## 🛠 Tech Stack

- **Frontend**: React + Vite
- **Styling**: Tailwind CSS
- **State Management**: React Context API + Local Storage
- **Visualization**: Recharts
- **Icons**: Lucide React

## 🏁 Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd spendwise-tracker
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to start tracking.
